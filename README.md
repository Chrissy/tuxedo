[Tuxedo No.2](http://tuxedono2.com) is an online cocktail resource. It emulates the creativity, curation, and organizational principles of great printed cocktail books, but recipes are indexed, searchable, and free.

## Static export

Tuxedo No.2 can be exported as a static site for Cloudflare Pages. See [docs/cloudflare-pages-migration.md](docs/cloudflare-pages-migration.md) for the export, deploy, verification, cutover, and rollback runbook.

The committed source data archive lives in [db/archive](db/archive). See [docs/agent-notes/static-site-preservation.md](docs/agent-notes/static-site-preservation.md) for preservation notes.
